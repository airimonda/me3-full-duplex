T−10 min Before you start

  • The Mac and the Pi are on the same network. Check the Mac server: curl -s localhost:8300/health should print 200-style JSON.
  • Watson is running on the Pi: ssh watsonpi 'pgrep -fl pipecat_assistant' shows one process. If not: ssh watsonpi 'setsid nohup bash ~/me3/run_live.sh >/dev/null 2>&1 </dev/null &'
  • The task server is running on the Pi: ssh watsonpi 'pgrep -fl tasks_mcp'. If not: ssh watsonpi 'setsid nohup bash ~/me3/run_tasks_mcp.sh >/dev/null 2>&1 </dev/null &'
  • Wait 2 minutes after any restart. The voice model loads for about 100 s, and speech recognition is slow until it finishes.
  • Say "Watson" once. You should hear "Yes? I'm listening." in the male am_michael voice.
  • If Watson ignores you (log shows stranger_ignored), restore your voice profile, then restart Watson:
ssh watsonpi 'cp ~/me3/voice_profile_nov6_good.npy ~/me3/voice_profile.npy; pkill -f "[p]ipecat_assistant.py --mic"'

Speak close to the USB mic. Watson only answers the enrolled owner, so a classmate cannot drive the main demo.

0:00 · 30 s Opening

Most voice assistants are walkie-talkies: you talk, they talk, and nobody interrupts. Watson is full duplex. It listens while it speaks, so you can cut it off, talk over it, or say "yeah" without derailing it.

It also has to decide who it is listening to. Its own voice comes back through the microphone, and so does everyone else in this room. I'll show you how it handles both.

0:30 · 60 s How it works

The Raspberry Pi is the ears and mouth. It runs voice activity detection, end-of-turn detection, interruption handling and playback. My Mac is the brain. It runs Whisper for speech recognition and Kokoro for the voice, and it calls a fast language model, GLM 5.3 Flash, for replies and tool calls. Everything is one Pipecat pipeline. Big jobs go to an MCP server we built that runs on the Pi: it hands them to a coding agent, pi.dev, locked inside a sandbox folder, and opens the result on screen when it's done.

Two problems took most of the work. First, echo. The speaker is as loud at the mic as I am, and hardware echo cancellation gave us almost nothing. So Watson decides by who is speaking: it compares each interruption against its own voice and against my enrolled voice. Second, my accent. Whisper hears "Watson" as "button", "Hudson" or "what's on", so the wake word is tuned to the mishearings in our own logs.

Speech recognition is fast. The slow part is the language model's first word, which takes 4 to 7 seconds on a real tool call. That's the next thing to fix.

5:15 · 30 s What's left

Three honest limits. Replies start slowly because of the language model. "Stop" takes up to two seconds, because we confirm the voice before stopping. And echo cancellation on this hardware didn't work, so everything rests on telling voices apart. That's why Watson speaks in a voice deliberately unlike mine.
